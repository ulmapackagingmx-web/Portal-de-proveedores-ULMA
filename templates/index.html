¿Cómo ingresar un registro?

Carga de XML (Múltiples)

Sube uno o varios archivos XML de facturas. El sistema extraerá automáticamente el RFC, Nombre, Total, UUID y demás datos fiscales.

Extracción Texto / Correo

Copia y pega el contenido de un correo o texto. La Inteligencia Artificial buscará montos, nombres y conceptos para crear el registro.

Carga Masiva (Excel)

Utiliza el layout definido en Excel para importar decenas de registros a la vez de forma rápida y sencilla.

Registro Manual

Captura manualmente un registro (como reembolsos o traspasos) indicando centros de costo y adjuntando comprobantes en PDF.
